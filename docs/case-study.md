# FormLab 케이스 스터디

위시캣과 포트폴리오에 옮겨 쓰기 위한 초안입니다.

라이브: https://toy-formlab.vercel.app
코드: https://github.com/pung8146/toy-formlab

## 한 줄 소개

실제 상품 3D 모델로 만든 라운지 체어 configurator.

## 개요

가구 쇼핑몰이 상품 페이지용으로 만든 3D 모델을 받아, 웹에서 원단·프레임·금속 마감을 바꿔 보는 제품 구성기로 만들었습니다. 외주에서 흔한 "클라이언트가 준 모델을 웹 configurator로" 흐름을 그대로 재현했습니다. 완성한 구성은 저장하거나 링크로 보낼 수 있고, 링크를 연 사람은 서버나 계정 없이 같은 구성을 봅니다.

역할: 기획, 3D 에셋 최적화, 인터랙션, 프런트엔드 개발 전체
기술: React, TypeScript, Three.js, React Three Fiber, Zustand, Vite, glTF Transform

## 핵심 결정

**받은 모델을 웹에 맞게 줄였습니다.** 원본 4.13 MB를 Meshopt 압축과 WebP 텍스처로 약 760 KB까지 줄였습니다. 부품을 구분하는 노드와 재질 이름은 압축 후에도 남도록 병합 옵션을 껐습니다.

**색은 텍스처를 바꾸지 않고 계수로 입혔습니다.** 원단 무늬와 결은 공용 텍스처로 두고 색과 벨벳 광택만 바꿔서, 원단 색을 늘려도 다운로드가 늘지 않습니다.

**그림자는 한 번만 굽습니다.** 의자 형태는 바뀌지 않고 색만 바뀌므로, 그림자 맵을 모델 로드 직후 한 번 만들고 다시 그리지 않습니다. 그 덕분에 그림자가 있어도 프레임당 삼각형은 모델 한 번 분량입니다.

**3D 없이도 끝까지 쓸 수 있게 만들었습니다.** 모든 옵션은 일반 HTML 폼이 원본이고, 3D 클릭은 보조 경로입니다. WebGL을 쓸 수 없거나 모델 다운로드가 실패해도 현재 구성을 유지한 채 편집과 공유를 계속할 수 있습니다.

## 구현한 기능

- 원단 6종, 프레임 3종, 금속 부품 3종 마감 변경과 3D 직접 선택
- 회전, 줌, 4개 시점, 버튼만으로 하는 카메라 조작
- 프리셋 저장, 불러오기, 삭제
- 서버 없는 공유 링크와 잘못된 링크 거부
- 모바일 레이아웃, 키보드 조작, reduced motion
- 3D·모델 로드 실패 시 2D 대체 화면과 재시도

## 품질 확인

단위 테스트와 브라우저 E2E 테스트로 설정 검증, 공유 링크, 저장 실패, 접근성(axe), 모델 다운로드 실패와 재시도, 컨텍스트 손실 복구, 리소스 누수, 렌더 예산을 확인했습니다.

## 크레딧

3D 모델은 Wayfair의 SheenChair(CC0, Khronos glTF 샘플)를 사용했습니다. 모델링은 제 작업이 아니며, 이 프로젝트의 범위는 에셋 최적화와 웹 configurator 구현입니다.
