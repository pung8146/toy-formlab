# FormLab 케이스 스터디

Work 섹션과 위시캣 포트폴리오에 옮겨 쓰기 위한 초안입니다.

라이브: https://toy-formlab.vercel.app
코드: https://github.com/pung8146/toy-formlab

## 한 줄 소개

부품별 형태와 마감을 고르고 불을 켜 보는 3D 램프 configurator.

## 개요

가구·조명 커머스에서 쓰는 제품 구성기를 램프 한 종으로 구현했습니다. 받침, 기둥, 암, 갓을 각각 고르면 형상과 재질이 즉시 바뀌고, 8가지 형태 조합과 부품별 마감을 만들 수 있습니다. 완성한 구성은 저장하거나 링크로 보낼 수 있고, 링크를 연 사람은 서버나 계정 없이 같은 구성을 봅니다.

역할: 기획, 3D 모델링(코드), 인터랙션, 프런트엔드 개발 전체
기술: React, TypeScript, Three.js, React Three Fiber, Zustand, Vite

## 핵심 결정

**불을 켜는 순간을 화면의 중심으로 삼았습니다.** 색과 형태 변경은 모든 구성기에 있습니다. 램프라는 제품에서만 가능한 장면을 넣기 위해, 버튼 하나로 스튜디오가 어두워지고 바닥에 빛이 떨어지게 만들었습니다.

**3D 없이도 끝까지 쓸 수 있게 만들었습니다.** 모든 옵션은 일반 HTML 폼이 원본이고, 3D 클릭은 보조 경로입니다. 키보드만으로 편집과 저장, 공유가 되고, WebGL을 쓸 수 없거나 GPU 컨텍스트를 잃어도 현재 구성을 유지한 채 계속 작업할 수 있습니다.

**외부 파일 없이 램프를 코드로 생성했습니다.** 회전체와 튜브로 형상을 만들고 스튜디오 반사도 코드로 만들어서, 3D 자산을 내려받다 실패할 경로가 없습니다. 초기 전송량은 약 700 KiB입니다.

**움직일 때만 렌더링합니다.** 조작과 전환이 끝나면 렌더 루프를 멈춰 배터리와 GPU를 쓰지 않습니다.

## 구현한 기능

- 부품별 형태, 재질, 색 변경과 3D 직접 선택
- 회전, 줌, 4개 시점, 버튼만으로 하는 카메라 조작
- 점등과 어두운 스튜디오 전환
- 프리셋 저장, 불러오기, 삭제
- 서버 없는 공유 링크와 잘못된 링크 거부
- 모바일 레이아웃, 키보드 조작, reduced motion
- 3D 실패 시 2D 대체 화면과 복구

## 품질 확인

단위 테스트 46개와 브라우저 E2E 테스트로 설정 검증, 공유 링크, 저장 실패, 접근성(axe), 컨텍스트 손실 복구, 리소스 누수를 확인했습니다.
