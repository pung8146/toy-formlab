## 성능 실측

환경: production build, Windows 11, Chromium headless, NVIDIA GeForce RTX 4060 Ti, 1440×900. 네트워크는 10 Mbps / RTT 80 ms 에뮬레이션, 캐시 비활성, 3회 실행입니다.

| 항목 | 목표 | 실측 | 판정 |
|---|---|---|---|
| 초기 전체 전송량 | 1.5 MiB 이하 | 1,423 KiB | 통과 |
| shell JS (gzip) | 180 KiB 이하 | 73 KiB | 통과 |
| 지연 3D JS (gzip) | 650 KiB 이하 | 281 KiB | 통과 |
| 폼 사용 가능 | 1.5초 이내 | 323 / 333 / 321 ms | 통과 |
| 첫 조작 가능한 3D | 5초 이내 | 2217 / 2187 / 2194 ms | 통과 |
| 삼각형 | 50k 이하 | 43,264 | 통과 |
| draw calls | 40 이하 | 5 | 통과 |
| 회전 중 프레임 | 참고 | 중앙값 16.7 ms / p95 16.7 ms | 고성능 GPU 기준 |
| 유휴 렌더 | 없음 | 정지 확인 | 통과 |
| 50회 옵션 교체 | 증가 없음 | geometry·texture·program 동일 | 통과 |

전송량의 JS·CSS는 gzip 환산값이고 모델·이미지·폰트는 파일 크기입니다. 고성능 데스크톱 GPU 결과이며 저가 노트북이나 휴대폰 성능을 뜻하지 않습니다.
