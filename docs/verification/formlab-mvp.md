## 자동 검증

| 명령 | 결과 |
|---|---|
| `npm run typecheck` | 오류 0 |
| `npm run lint` | 오류 0 |
| `npm run test:unit` | 3개 파일, 46개 통과 |
| `npm run test:e2e` | 37개 통과 (Chromium, 소프트웨어 렌더링) |
| `npm run build` | 성공 |
| `npm audit --omit=dev` | 운영 의존성 취약점 0건 |

개발 도구(ESLint 계열)에는 moderate 경고 9건이 남아 있습니다. 배포 번들에는 포함되지 않으며, 강제 업데이트는 호환성을 깨므로 적용하지 않았습니다.

## 성능 실측

환경: production build, Windows 11, Chromium headless, NVIDIA GeForce RTX 4060 Ti, 1440×900. 네트워크는 10 Mbps / RTT 80 ms 에뮬레이션, 캐시 비활성, 3회 실행입니다.

| 항목 | 목표 | 실측 | 판정 |
|---|---|---|---|
| 초기 전체 전송량 | 1.5 MiB 이하 | 679 KiB | 통과 |
| shell JS (gzip) | 180 KiB 이하 | 74 KiB | 통과 |

전송량의 JS·CSS는 gzip 환산값입니다. 로컬 프리뷰 서버는 압축하지 않으므로 시간은 보수적인 값입니다. 고성능 데스크톱 GPU 결과이며 저가 노트북이나 휴대폰 성능을 뜻하지 않습니다.
